# Sgian 0.2.0 — draft release notes

Prepared 2026-11-23. This version is not tagged or published. The latest
published release remains the source-only `v0.1.0`; installers described below
are awaiting the [release gates](../public-readiness.md).

## Highlights since 0.1.0

- Codex and Gemini join Claude and Droid as chat-native agent backends,
  with per-provider executable settings, resume support and permission modes.
- Saved remote workspaces connect through SSH or AWS SSM, with machine
  switchers in all three clients and recovery when a tunnel drops.
- Shared project notes appear alongside projects on the board. Kranz can
  request bounded terminal execution through signed grants with ledger receipts.
- Accessibility improvements add clearer control labels, terminal text
  exposure and screen-reader preferences across the desktop and web clients.
- Native-client fixes improve pane sizing, workspace recovery and Windows
  agent profiles. macOS terminal search clears stale state when its context
  changes, and chat messages remain readable in narrow splits.
- Security hardening strengthens loopback request validation, credential
  revocation, process isolation, file confinement and terminal link handling.
  Dependency updates address current URL, cookie, Rustix and Tokio advisories
  and remove unused, unmaintained PTY dependencies.

See the [full changelog](../../CHANGELOG.md) for technical details and the
[dependency review](../reviews/dependencies-0.2.0.md) for the remaining
inactive optional Chrono advisory.

## Distribution and acceptance

The intended installer set is a universal macOS app, Windows x64 MSIX with
App Installer updates, and Linux AppImage/Debian packages. Production signing,
clean-machine installs and installed updates still need acceptance before
publication. Development builds are not signed release installers.

Windows hands-on acceptance will run later on the separate Windows machine.
The [November 24 Mac pass](../acceptance-macos-2026-11-24.md) covers DMG packaging,
Intel-only smoke under Rosetta, live Claude/Codex replies, the native composer,
keyboard take/hand-back and conversation restoration. Physical Intel Mac
execution, sleep/wake, VoiceOver and provider permission prompts remain open.
Gemini live acceptance is blocked by the available account's provider-side
client rejection. Droid/Factory is deferred because no subscription is
available. Earlier `0.1.0` development artifacts and checks
are recorded separately and must not be relabelled as `0.2.0` acceptance.

The reserved `0.0.1` crates.io placeholders are unchanged; this preparation
does not publish Rust crates or change public updater feeds.
