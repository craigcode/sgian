## Design note on S3

The three agent requests carry no holder. Adding one would touch about
fifty call sites, so the lease check runs on the connection's identity:
enforced for credentials, which is where M6 made its claim. The root
workspace token under `identity: open` stays coordination for agent
control, as for any unattributed root write; under `required` root cannot
write at all.

## Accepted, unchanged

Same-user processes are inside the boundary; a copied `sgc_` token is that
client; `ctl hook --pid` is caller-chosen and needs `write` from a
credential; Windows agent kill is the direct child only; the dossier writes
scrollback where `--out` says; OSC 52 is counted and forwarded; explicit
`env` beats `scrub_env`.
